# Dated reports

These reports record individual experiments and diagnoses. Start with the
[current guides](../README.md) for operating instructions.

- `ble-c6-*`: BLE delivery, signal quality, and timing.
- `espnow-*`: gateway transport, receiver scheduling, throughput, and endurance.
- `gateway-*`, `receiver-expiry-*`, and `usb-reference-overload-*`: buffering and recovery investigations.
- `loss-15min-*` and `room-transport-*`: measured transport performance.
- `live-model-diagnosis-*` and `phase-model-evaluation-*`: exploratory model evaluation.
