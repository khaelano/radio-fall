# Archive

The documents in this directory describe retired transports and tools: the BLE
transport and its delivery policy, the wireless transmitter control path, and
the session-archive pilot tooling. They are kept for history and are not current.
Commands, configuration paths and wire contracts here may no longer match the
repository, and some files they name have been removed. For current behavior,
see [project knowledge](../project-knowledge.md),
[radio configuration](../radio-configuration.md) and
[dataset format](../dataset-format.md).
